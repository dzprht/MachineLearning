# Каталог реализованных моделей

Это человекочитаемый индекс замороженных агентов. Машинным источником истины остаются `metadata.json` и `*.metadata.json`, которые проверяет `training.poolctl`; роли train/validation/test назначаются только в `training/opponent_pools.json`.

Статус **smoke** означает, что entrypoint загружается как обычный Kaggle-файл и проходит характерный сценарий среды. Это ещё не сравнительный benchmark и не оценка силы.

## Простые контрольные циклы

| ID | Концепт | Главное отличие | Полезность при отборе |

| `wheat_loop_v1` | Одна клетка пшеницы | Дешёвый короткий цикл, предложение корма | Контроль рынка wheat; smoke |
| `tomato_loop_v1` | Одна клетка томата | Четыре ежедневных повторных урожая | Контроль длинного ongoing-цикла; smoke |
| `strawberry_loop_v1` | Одна клетка клубники | Четыре урожая через день | Медленный премиальный ongoing-профиль; smoke |
| `melon_loop_v1` | Одна клетка дыни | Длинный цикл и крупная разовая продажа | Контроль отложенной выручки; smoke |

## Средние производители и рыночные профили

| ID | Концепт | Главное отличие | Полезность при отборе |
| --- | --- | --- | --- |
| `carrot_field_v1` | Поле моркови до 12 клеток | Наём по нагрузке, немедленная продажа | Объёмное давление на carrot; парный контроль для buffered seller |
| `tomato_field_v1` | Поле томата до 12 клеток | Повторные урожаи на многих клетках | Устойчивый поток tomato |
| `melon_field_v1` | Поле дыни до 12 клеток | Пакетные крупные продажи | Сильные ценовые импульсы melon |
| `staggered_mix_v1` | Конвейер wheat/carrot/tomato | Разные культуры и возраста одновременно | Проверка временных признаков наблюдения |
| `town_demand_v1` | Производитель под спрос | Выбор новой посадки по цене, магазинам, себестоимости и собственному предложению | Адаптивный market-aware train-соперник |
| `crop_follower_v1` | Следует культуре соперника | Намеренно усиливает конкуренцию в видимой специализации | Стресс-сценарий давления; не считать сильным по умолчанию |
| `crop_avoider_v1` | Уходит от культуры соперника | Оценивает видимое предложение к сроку своего сбора | Контрастная opponent-aware реакция |
| `buffered_seller_v1` | Морковное поле с буфером | Партии до 8 единиц, порог 92% базы, ожидание не более 3 дней, аварийная продажа | Парный тест скрытого запаса против `carrot_field_v1` |

| ID | Концепт | Главное отличие | Полезность при отборе |

| `mixed_farm_v1` | Смешанная ферма | Wheat для резерва корма, гуси, carrot/tomato, условное применение удобрения | Самый многомеханический соперник; лучше держать вне первого простого диагностического пула |

## Практика составления пулов

- Не распределять близкие варианты одного семейства между validation и test как будто это новые типы поведения.
- Для train выбирать несколько разных осей: короткий цикл, объёмное поле, адаптация к спросу и животноводство; не отдавать основной вес множеству похожих monocrop-версий.
- Парные агенты полезны для диагностики одной причины: `carrot_field_v1` ↔ `buffered_seller_v1`, `town_demand_v1` ↔ `crop_expander_v1`, single-animal ↔ ranch, follower ↔ avoider.
- Окончательное назначение делать после общего benchmark на одинаковых seed и обеих позициях.
- 2026-09-08: `train_v1`/`validation_v1`/`test_v1` заполнены агентом как первое рабочее распределение для запуска обучения RL-закупщика (IDEA-004/008), см. результат IDEA-003 в `docs/IDEAS.md`. Это не замена общему benchmark; состав подлежит пересмотру после него.
