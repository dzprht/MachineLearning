# Versioned agents

Каждая зафиксированная версия агента хранится в отдельном неизменяемом каталоге:

```text
agents/
└── baselines/
    └── carrot_loop_v1/
        ├── main.py
        └── metadata.json
```

`main.py` содержит Kaggle-совместимую функцию `agent(obs)` и не импортирует код из других версий. Поэтому конкретный файл можно передать в `env.run`, скопировать в submission или включить в фиксированный пул соперников без зависимости от текущей разрабатываемой модели.

`metadata.json` фиксирует назначение, происхождение, интерфейс, ограничения и результаты проверки версии. Замороженная версия имеет `schema_version: 1`, `status: "frozen"`, явный список `artifact_files` и SHA-256 этих файлов. После заморозки код не переписывается: улучшение получает новый каталог и новый `id`.

Агенты обнаруживаются автоматически командой:

```bash
../ml_venv/bin/python -m training.poolctl list-agents
```

Роли версии не зашиваются в её metadata. Конкретный эксперимент назначает версии в именованные train/validation/test-пулы через `training/opponent_pools.json`; разрешённый состав и hashes затем копируются в manifest запуска.

Корневой `main.py` — удобная текущая точка входа. Она может меняться и сейчас лишь экспортирует выбранную замороженную версию.
